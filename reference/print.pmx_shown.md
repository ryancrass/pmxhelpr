# Print a layer visibility object

Prints a
[`plot_vpc_shown()`](https://ryancrass.github.io/pmxhelpr/reference/plot_vpc_shown.md)
or
[`plot_gof_shown()`](https://ryancrass.github.io/pmxhelpr/reference/plot_gof_shown.md)
object as one `key TRUE/FALSE` line per layer.

## Usage

``` r
# S3 method for class 'pmx_shown'
print(x, ...)
```

## Arguments

- x:

  A `vpc_shown` or `gof_shown` object.

- ...:

  Currently unused.

## Value

`invisible(x)`.
